Get started

几分钟跑起 GroveMQ

从单机 Broker 到启用 A2A 能力，再到用标准 A2A SDK 调用 Agent——按场景选择下面的接入路径。

Quick start

本地构建与运行

前置条件：Go 1.25+，以及任意 MQTT 客户端（MQTTX 或 mosquitto-clients）。

1

克隆仓库

获取最新源码。

shell复制
$ git clone https://github.com/RiemannChow/GroveMQ.git
$ cd GroveMQ
2

构建

在仓库根目录生成可执行文件。

shell复制
$ go build ./cmd/grovemq
3

启动 Broker

从仓库根目录运行，以便读取 config.yaml。

shell复制
$ ./grovemq
# 监听：MQTT :1883 · gRPC :8081 · Metrics :8082 · Dashboard :18083
4

连接测试

任意标准 MQTT 客户端即可接入。

shell复制
$ mosquitto_sub -h localhost -p 1883 -t "test/topic"
$ mosquitto_pub -h localhost -p 1883 -t "test/topic" -m "Hello GroveMQ"
Deploy

集群、Docker 与 Kubernetes

本地三节点集群

脚本构建并启动 1883 / 1884 / 1885 三个节点，附集群测试工具。

start-cluster.sh

Docker Compose

docker-compose-cluster.yaml 一键拉起集群；单节点也可用 docker run 映射端口。

compose v2

Kubernetes

提供 StatefulSet 与 headless service 清单，节点自动发现；持久化用每节点独立卷。

k8s/
持久化需要设置 GROVEMQ_DATA_DIR：未设置时所有状态只在内存，重启即丢失；设置后会话、retained 消息与 A2A Task 记录均落盘。
Enable A2A

启用 Agent 能力

A2A 能力默认关闭。在 config.yaml 中按需开启 Registry、网关与身份绑定。

config.yaml · A2A section复制
broker:
  a2a_registry:
    enabled: true
    validate_schema: strict   # strict (A2A 1.0) | loose (EMQX 风格)
    binding_url: "mqtt://localhost:1883"
    require_security_metadata: false
    allowed_jku_prefixes: []

  a2a_gateway:
    enabled: true
    timeout_seconds: 5
    tokens: {"my-secret-token": "sdk-service"}  # Bearer -> principal

  a2a_request_auth:
    policy: agent_or_gateway  # off | caller | agent_or_gateway
    allowed_clients: ["grovemq-gateway"]
    allowed_usernames: ["sdk-service"]
A2A 相关配置是启动期配置，修改后需要重启 Broker；auth / ACL / hooks 支持热重载。
Publish a card

发布第一张 Agent Card

把符合 A2A 1.0 的 Card JSON 发布到保留主题，即完成注册与发现。

shell · register agent复制
$ mosquitto_pub -h localhost -p 1883 \
    -t '$a2a/v1/discovery/acme/fleet/router-agent' \
    -f agent-card.json \
    -q 1 -r

# Client ID 必须等于三段地址 acme/fleet/router-agent
# 通过 Admin API 查看注册结果：
$ curl http://localhost:18083/api/v5/a2a/agents

注销时向同一主题发布空载荷并设置 RETAIN=1；Registry 启用后还会从 retained Card 在启动时自动重建索引。

Connect paths

四种接入方式

接入方入口说明
MQTT 设备 / 客户端mqtt://host:1883标准 MQTT v3.1.1 / v5.0 客户端
A2A SDKhttp://host:18083/a2a/v1/<address>仅改端点 URL，Bearer token 鉴权
Agent Worker$a2a/v1/.../requests原生订阅请求主题，或用 $share 组成工作池
运维 / Dashboardhttp://host:18083Admin API、A2A agents / stats、配置热重载
生产部署前请替换 config.yaml 中的演示凭据（如 admin / admin123），并按网络暴露面配置 auth、ACL 与 TLS。
