GroveMQ 是一个用 Go 编写、基于 Actor 模型的 MQTT Broker。它把高可靠消息传输与 broker 中立的 A2A over MQTT 契约放在同一套内核里——让海量设备与 AI Agent 通过同一条实时通道协作。

快速开始 → 了解 Agent 能力

Go 1.25+ · Apache 2.0 · MQTT v3.1.1 / v5.0

~/GroveMQ
$ go build ./cmd/grovemq
$ ./grovemq

一个内核，覆盖从连接到协作

GroveMQ 用轻量 Actor 模型管理会话，把可靠性、扩展性与安全能力做进 Broker 核心。

A2A over MQTT

让 Agent 发现与任务交换，跑在 MQTT 之上

GroveMQ 在标准 MQTT 之上定义了一套 broker 中立的 A2A 契约：保留主题承载 Agent Card，MQTT 5 User Properties 承载协议语义，请求、状态与工件各走独立主题。

  • Agent 发现：$a2a/v1/discovery 保留主题，订阅即得在线状态
  • 任务交换：Response Topic + Correlation Data 配对，语义错误走 PUBACK
  • 标准兼容：对齐 A2A 1.0 数据模型与 JSON-RPC 方法，SDK 只改端点即可接入
  • 默认零回归：全部 A2A 特性默认关闭，不启用时就是普通 MQTT Broker

agent-card.json · A2A 1.0复制
// 发布到保留主题即完成注册
$ mosquitto_pub -h localhost -p 1883 \
    -t '$a2a/v1/discovery/acme/fleet/router-agent' \
    -f agent-card.json -q 1 -r

// supportedInterfaces 中的 binding
{
  "url": "mqtt://grovemq:1883",
  "protocolBinding": "A2A-over-MQTT",
  "protocolVersion": "1.0"
