Layered design

配置热重载，无需重启

向进程发送 SIGHUP 或调用 Admin API POST /api/v5/reload，即可重新加载 auth、ACL 与 hooks，不中断在线连接。监听端口只在启动时绑定，修改端口仍需重启。

A2A Registry、Gateway 与请求身份绑定属于启动期配置，修改后需要重启 Broker。
